# DJ Holly Weed — Website

Static site, no build step. Fully responsive, self-hosted fonts, working nav/links.

## Deploy (GitHub Pages)
The repo `thecreatorie/djhollyweed` already serves at
`https://thecreatorie.github.io/djhollyweed/`.

1. Delete the old files in the repo (`index.html`, `image-slot.js`).
2. Upload everything in THIS folder to the repo root (**Add file → Upload files**, drag the
   `index.html`, `README.md` and the whole `assets` folder in).
3. Live in ~1 minute.

### Custom domain (djhollyweed.com)
Settings → Pages → Custom domain → `djhollyweed.com`. At the registrar add
A records for `@` → 185.199.108.153 / .109.153 / .110.153 / .111.153 and a
CNAME for `www` → `thecreatorie.github.io`. Tick *Enforce HTTPS*.

## Swap in real photos — no code edits needed
The placeholder images are real files. Overwrite them (same filename) and you're done:

| File | What goes there | Ideal size |

| `assets/img/about.jpg` | Booth or crowd shot, landscape | 1400×1200 |

| `assets/img/og.jpg` | Link-preview card (already branded — optional swap) | 1200×630 |
